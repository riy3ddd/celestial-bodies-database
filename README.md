# Celestial Bodies Database 🌌

A relational database project built as part of the freeCodeCamp Relational Database certification.

## Project Overview

This project focuses on designing and managing a PostgreSQL relational database representing celestial bodies in the universe.

It demonstrates practical SQL skills through database creation, table relationships, primary keys, foreign keys, and data management.

## Technologies Used

- PostgreSQL
- SQL
- Relational Database Design

## Key Concepts

- Creating and managing databases
- Designing relational tables
- Primary and foreign keys
- Establishing relationships between tables
- Inserting and querying data
- Using SQL constraints

## Project Structure

- `universe.sql` – SQL script containing the database structure and data.

## How to Run

1. Install PostgreSQL.
2. Create a new database.
3. Execute the `universe.sql` script.
4. Explore the database tables and relationships.

## Learning Outcomes

- Improved understanding of relational database design.
- Practical experience writing SQL queries.
- Hands-on experience with PostgreSQL.
